res2jobWorks Roadmap and Architecture

Self-contained companion for .vault/PLAN.md and the feature-plan sequence created on 2026-06-03. This view keeps the product boundaries, implementation order, and validation gates visible before the first code scaffold.

Product Boundary

Public-generic, local-first job-search workbench. Personal workflow is dogfooding, not the product default.

MVP 1

Profile and job import, cited evaluation, SQLite tracking, dashboards, exports, and generated agent wrappers.

Phase 2

Resume tailoring, cover letters, answer drafting, and PDF/DOCX generation after evaluation and tracking stabilize.

Feature Plan Sequence

001 Bootstrap Core Contracts

Monorepo skeleton, command envelope, public fixtures, and tests.

002 SQLite Model

Profiles, jobs, evaluations, citations, applications, notes, exports, and agent runs.

003 Import, Evaluate, Export

Manual imports, rubric evaluation, cited reports, tracker exports.

004 Clients and Wrappers

CLI, TUI, web dashboard, and generated agent wrappers over one registry.

005 Browser Automation

Safe extraction, draft/fill/review, evidence capture, no default submission.

006 Phase 2 Documents

Tailoring, letters, answers, ATS checks, and PDF/DOCX generation.

Risk Controls

Private data leakage

Use public-generic fixtures and keep personal dogfooding data outside public defaults.

Client drift

Generate wrappers from the command registry and verify envelopes across clients.

Opaque LLM output

Store rubric versions, citations, provider metadata, and reversible evaluation records.

Auto-submit ambiguity

Browser automation defaults to extraction, draft, fill, review, and evidence capture only.
