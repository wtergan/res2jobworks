# Public Fixtures

The examples in `templates/` and `examples/` are fictional, public-generic
fixtures. They exist to validate contracts and demonstrate safe project shape.

Fixture rules:

- Do not include a real private resume, tracker, employer history, or application
  record.
- Label example records as fictional fixture data.
- Keep provider keys, tokens, cookies, and local machine paths out of fixture
  files.
- Treat authorization headers, bearer tokens, session cookies, access tokens,
  OAuth material, and private local workspace files as private data.
- Treat Markdown and CSV outputs as generated artifacts, not canonical product
  state.
