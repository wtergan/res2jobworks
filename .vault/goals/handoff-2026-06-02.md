# res2jobWorks Handoff

## Session Context

This project was brainstormed from an earlier idea named `Res2JobFit`, originally centered around building a personal AI job application helper inspired by resume/job-search tools.

During the brainstorm, the project was renamed to `res2jobWorks` and reframed as a public-generic, local-first job-search workbench.

## Decisions Made

- Public-generic from day one.
- Monorepo layout is preferred.
- MVP 1 prioritizes job evaluation and application tracking.
- Resume tailoring, cover letters, and PDF/DOCX generation are phase 2.
- SQLite is the source of truth.
- Markdown and CSV are export formats.
- TUI dashboard and equivalent browser/web dashboard are both desired.
- Agents should be clients over a shared core, not separate sources of truth.
- Codex, Hermes, Claude, OpenCode, Gemini, and similar tools should be supported through generated wrappers/skills.
- Browser automation is desirable, but default behavior must be draft/fill/review rather than auto-submit.
