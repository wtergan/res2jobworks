# Fixture Job: Product Operations Analyst

This fictional job description is public-generic test data for res2jobWorks.

## Organization

Northstar Civic Tools is a fictional public-interest software studio.

## Role Summary

The Product Operations Analyst helps a small team evaluate user feedback,
maintain implementation trackers, and coordinate releases for local-first data
tools.

## Responsibilities

- Translate support notes and interview findings into structured product issues.
- Maintain a lightweight application and project pipeline with clear status
  history.
- Write concise release notes and internal decision records.
- Coordinate with engineering, design, and user research partners.

## Requirements

- Experience organizing ambiguous operational workflows.
- Comfortable with spreadsheets, Markdown, and issue trackers.
- Basic familiarity with Python or SQL for inspecting local data.
- Strong written communication and evidence-based prioritization.
